# ADR-016：V1.0 发布范围与验收口径

日期：2026-10-24。状态：已接受（维护者要求发布 V1.0）。

## 背景与决策

维护者要求把当前工程作为 V1.0 公开发布。仓库本身此前把 V1.0 定义为“Windows 与 macOS 双平台，并具备签名与独立干净机证据”。要在不伪造证据的前提下交付 V1.0，需要把**产品范围**与**验收口径**分开定义：

- 产品范围：Windows 与 macOS 均为一等目标平台，源码在两者上构建；macOS 的构建与测试由 CI 在真实 macOS 运行器上执行。
- 验收口径：只在真实执行过的环境上标记 PASS。**没有实机人工验收的平台能力一律保持 UNVERIFIED**，不以“CI 通过编译”代替输入设备、辅助技术、休眠、多屏或通知送达验收。

因此 V1.0 的发布声明为：*功能完整、可离线使用的 Windows/macOS 桌面应用；Windows 已通过自动化与人工合成流程验证，macOS 通过 CI 构建与测试，其余平台能力按[平台矩阵](../platform-test-matrix.md)逐项标注。*

## 具体约定

| 事项 | 决定 |
|---|---|
| 版本号 | `1.0.0`（源码 `TILO_VERSION`）；历史 `1.0.0-rc.*` 记录保留为历史 |
| 工具链 | 固定 Qt 6.10.2；Windows 支持 MinGW 与 MSVC 两套预设，macOS 使用 Apple Clang |
| CI | 每次推送与 PR 在 Windows(MSVC)、macOS arm64、macOS x86_64 上构建并运行全部 CTest；失败即不合并 |
| 发布物 | 打 `v*` 标签时构建 Windows x64 与 macOS arm64 包，附 SHA256 侧车，生成草稿 Release 供人工核对 |
| 签名与安装器 | **未提供**。发布物为免安装目录包；不宣称已签名、已公证或已通过安装器安装 |
| 干净机验证 | 未执行。CI 运行器不等于干净终端用户机器 |
| 许可证 | 源码 MIT；Qt 运行时许可与再分发条款见[第三方说明](../third-party-notices.md)，发布包不附带 Qt SDK |
| 隐私 | 无账号、无遥测、无网络请求；数据仅存本机 |

## 后果

- README、发行说明与平台矩阵必须使用同一口径，不得出现“完整双平台 V1 已验收”这类超出证据的表述。
- 未签名安装包会在 Windows SmartScreen 与 macOS Gatekeeper 上产生警告，这是已知且已披露的限制，需要在发行说明中提示用户。
- 后续补签名、公证、安装器与干净机验收时，只需更新本 ADR 与平台矩阵，不需要改动产品范围。
