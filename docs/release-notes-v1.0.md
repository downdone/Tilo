# Tilo 1.0.0

Tilo 是一个离线优先的桌面任务管理与日历应用：收集、规划、安排、查看日历、在桌面组件上勾选，全部在本机完成。无账号、无云端、无遥测。

## 下载

- **Windows x64**：`Tilo-1.0.0-windows-x64.zip`（免安装，解压后运行 `tilo.exe`）
- **macOS（Apple Silicon）**：`Tilo-1.0.0-macos-arm64.zip`（解压后拖入「应用程序」）

每个包附 `.sha256` 校验文件。解压前请先比对：

```bash
# macOS / Linux
shasum -a 256 Tilo-1.0.0-windows-x64.zip
# Windows PowerShell
Get-FileHash .\Tilo-1.0.0-windows-x64.zip -Algorithm SHA256
```

## 已知限制（1.0.0）

- **未签名**：Windows 会显示 SmartScreen 提示，macOS 首次打开需在「系统设置 → 隐私与安全性」中允许。没有安装器，也不提供自动更新。
- **未在干净虚拟机上验收**：公布的结果来自开发者机器与 CI 运行器。
- **macOS 未做人工界面验收**：CI 会在 macOS arm64 与 x86_64 上构建并运行自动化测试，但界面手感和系统集成（菜单栏、Spaces、通知权限）尚未人工确认。
- **系统通知送达取决于系统权限**，应用内提醒记录始终保留。
- 数据只存在本机；不做云同步，也不读取或迁移旧品牌目录下的数据。

## 主要功能

- 收集箱 / 今天 / 即将到来 / 随时可做 / 以后再说 / 已完成六视图，支持持续关注今天、今晚分组与自定义排序。
- 领域、项目、分组、标签、检查清单；项目与领域互斥归属。
- 月/周日历、当天议程、跨日连续日程、独立桌面日历窗口。
- 本地事件：全天或定时、循环规则、提醒，并与任务多对多关联。
- 重复任务规则（按天/周/月/年、完成后 N 天）、幂等实例与手改保护。
- 透明桌面组件与 Mini 模式、置顶、锁定、鼠标穿透（可从托盘或设置解除）。
- WAL 一致快照、每日自动备份、JSON/CSV 导出、验证预览后的事务导入与备份恢复。
- 浅/深/跟随系统主题、100%–200% 文字、增强对比度、键盘操作与可访问名称。

## 升级与数据

- 数据库 schema 4。旧版本数据库在打开前会自动创建一致快照到 `backups/migrations`。
- 导入与恢复都会先预览、再整体替换；备份失败则不执行。
- 卸载只需删除程序目录；数据目录保留，可在「设置 → 关于」中查看路径。

## 从旧版本迁移

若你此前使用过 `Daymark` 命名的候选版本，Tilo 使用全新的数据目录（`Tilo/Tilo`），**不会自动迁移**。需要旧数据时，先完全退出两个程序，再把旧目录中的数据库复制为 `tilo.sqlite`，或从旧版导出 JSON 后在新版导入。
